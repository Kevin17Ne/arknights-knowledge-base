# 明日方舟 · 敌人与关卡机制

> 来源：PRTS「作战机制」（敌人类单位行动与坐标、敌人模型、波次、地块、位移）、「游戏数据基础」（重量/移速/阻挡半径/闪避）、「攻击范围」

## 1. 寻路（为什么敌人会那样走）
- 敌人用 **SPFA 最短路**寻路，始终选最短路径；同长度时选“能缩短空间距离”的路线。
- 地面/飞行两套寻路：地面不走“地面不可通行地块”（围栏、高台），飞行不走“飞行不可通行地块”。
- 类障碍物地块（<阻挡路线>）有寻路代价：普通障碍 **1000**；**地穴 1,000,000**（2023-02 修复后），所以“堵路让敌人自己跳坑”已基本失效。
- 侵入点与保护目标点都是**可通行**地块。
- 偏移量（ReachOffset）不为 0 会让敌人“贴墙走”；行动指令只规定目标点，敌人会尽一切办法到达，直到下一条指令。

## 2. 路径指令（读图基础）
| 指令 | 作用 |
|---|---|
| MOVE | 移动到指定位置 |
| WAIT_FOR_SECONDS | 到点后停驻 N 秒 |
| WAIT_FOR_PLAY_TIME | 全局时间到 N 秒后继续 |
| WAIT_CURRENT_FRAGMENT_TIME | 本兵团开始后 N 秒 |
| WAIT_CURRENT_WAVE_TIME | 本波次开始后 N 秒 |
| DISAPPEAR / APPEAR_AT_POS | 进传送（无敌透明）/ 瞬移出现 |
| PATROL_MOVE | 巡逻，循环路径（2023 起） |
| WAIT_BOSSRUSH_WAVE | 引航者试炼“休整”，下波次再出现 |

- 红线 = 地面敌人路线，黄线 = 飞行单位路线（画在模型位置，不是格子）。
- 敌人可凭空出现（空降兵、无人机、地图外飞入），不一定从侵入点来。

## 3. 波次结构
`波次 Wave > 兵团 Fragment > 小队 Action > 单个敌人`
- 小队 = 同一行动设置的一组同种敌人；小队动作包括 SPAWN、显示路径、BGM、敌情弹窗、预部署生效/撤回、局内演出等。
- 兵团 = 一段时间内的出兵；波次 = 更长时间段。
- 实用意义：**出兵是按波次脚本的**，所以“什么时候来什么”是可背的；代理失败常因帧数/击杀时间变化导致波次节奏错位。

## 4. 漏怪与通关判定
- 敌人走完所有指令 → 变黑消失、**扣除目标生命**并报警；只要还有“必须处理的敌人”且生命未耗尽，关卡不结束。
- 特例：`isUnharmfulAndAlwaysCountAsKilled` 不扣血只计数；**非首要目标**（铁砧、破片、注亡拟嗣等）无需处理即可通关；赞助无人机扣 0 血但仍算处理。
- 行动指令优先级高于阻挡：直接出生在目标点的敌人会立即进门（多数已修）。

## 5. 碰撞与阻挡
- 干员碰撞体积基本是 **半径 0.25 格**的圆；阻挡判定用“阻挡半径”。
- **地面阻挡半径 0.7071**（平方 0.49999）；**飞行阻挡半径 0.8944×倍率**（平方 0.79995）。
- 阻挡偏移：把干员空降到有敌人的格子，敌人会被推到以干员为圆心、半径 0.5 的圆边界上；多阻挡时后续敌人还会有 ≤0.2 的旋转偏移。
- 判定方式有三种：**碰撞箱**（最常用，索敌抬手）、**中点判定**（坐标在范围内）、**格子判定**（坐标四舍五入取格，坑/陷阱/睡眠范围）。
- 陷阱师地雷、麦哲伦停顿、黍三技能标记都用格子判定。

## 6. 朝向与弱点
- 敌人只有左右朝向；移动时按摄像机 POV 的左/右向量转向，攻击时转向目标（特殊攻击如火龙甩尾不转向）。
- **弱点部位**（落叶逐火起）：以敌人所在列为界，左侧格子的伤害=来自左侧，右侧=来自右侧；正对方向=正面伤害，背面=背面伤害。
- 推拉导致的失衡移动会让敌人面向来源。

## 7. 地块属性（部署限制的根源）
| 参数 | 含义 |
|---|---|
| tileKey | 地块种类（禁止部署/地面/高台/保护点/侵入点/传送口…） |
| heightType | 高度（低地/高地），影响阻挡与筛选 |
| buildableType | 玩家可部署类型：不可/仅近战/仅远程/全部 |
| passableMask | 敌人可通行：无/仅飞行/全部 |
| playerSideMask | 多维合作分边 |
| AdvancedBuildableMask | 地形标记（深水、涨潮、黑夜、坑道、阻流阀等） |
| isNonebuildableLike | 只允许“仅能部署在该地形”的单位（字格） |

## 8. 重量与位移（推拉体系核心）
力度等级：微小力(-1)、小力(0)、中力(1)、较大力(2)、大力(3)、大力+1(4)、特大力(5)

**推力位移 = f(力度 − 重量)**（近似）：
| 力度−重量 | 位移(格) | 时间(s) |
|---|---|---|
| ≤−3 | 0 | 0 |
| −2 | 0.12 | 0.2 |
| −1 | 0.44 | 0.4 |
| 0 | 1.7 | 0.8 |
| 1 | 2.14 | 0.9 |
| 2 | 2.96 | 1.07 |
| ≥3 | 3.53 | 1.17 |

**拉力**：力度−重量 ≤ −3 拉不动；−2 只蠕动；−1 拉近 0.35 倍初始距离；≥0 **必定拉到身前**。
- 实战：温蒂/崖心/雪雉等推拉干员的“力度”要和敌人重量对齐；重量 4 的敌人需要力度 ≥1 才推得动 1.7 格。

## 9. 移速与闪避
- 移动速度：每帧移动 `速度 × move_multiplier ÷ 帧率` 格；`move_multiplier` 默认 **0.5**（所以面板速度是视觉两倍）；速度下限 0.1。
- 闪避：多个闪避效果**叠乘**，`P = 1 − Π(1−Pᵢ)`。

## 10. 攻击范围
- 攻击范围是 1×1 方块拼成的多边形或圆；点选时**青色=治疗范围、橙色=攻击范围**。
- 常见：面前一格、身后一格、周围四格（曼哈顿≤1）、周围八格（切比雪夫≤1）、周围十二格（曼哈顿≤2，剑雨范围）。
- “攻击距离”属性可让多边形范围向正前方拉伸 1 格/点（圆形则加半径）。

## 11. 实战推论
1. **堵门/卡位**：利用寻路代价与阻挡偏移，可以把敌人挤到想要的位置；但别指望坑杀。
2. **飞行单位**：只走飞行路径、只能被“对空”攻击，起飞类干员（裂空炮手/巡空者）可挡飞行。
3. **高台限制**：地面干员上不了高台，远程干员下不了地面；部署类型由地块决定，不是干员决定。
4. **弱点机制**：多方向布阵可以打到“背面伤害”，部分活动关是硬性要求。
5. **推拉轴**：力度−重量表是温蒂/崖心/雪雉作业的计算基础，重量 3~4 的精英怪是分水岭。
6. **代理失败**：多因帧数、击杀时机、随机数导致波次错位；稳定代理要减少“看脸”技能与极限卡点。
