## 1. 属性系统（四层修饰器）

任何属性变化都归入四种计算方式，按顺序结算：

| 层级 | 名称 | 游戏内描述特征 | 叠加方式 |
|---|---|---|---|
| 1 | 直接加算 | “攻击力+30” | 各项相加 |
| 2 | 直接乘算 | “攻击力+50%” | 各项相加后 ×(1+Σ) |
| 3 | 最终加算 | “获得相当于XX攻击力的鼓舞” | 各项相加 |
| 4 | 最终乘算 | “攻击力提升至380%” | 各项相乘 |

最终属性：
`A_f = F_t × [ (A + D_p)(1 + D_t) + F_p ]`
- 最终乘算的每一项若为负，自动补正为“原值+1”（即变倍率）；`1+D_t<0` 时补正为 0。
- 之后受**数值范围**上下限约束。

**关键理解**：同名词条（如“攻击力+%”）互相加算，不同层级之间乘算——所以“堆同一种buff”收益递减，混搭不同层级收益最高。

## 2. 伤害公式

基本伤害 `A = 攻击力 × 攻击力倍率 + 附加攻击力`

| 类型 | 公式 | 说明 |
|---|---|---|
| 物理 | `max(0.05A, A − (1−I_p)·max(0, D−I_v))` | D=防御力；I_p 百分比穿透，I_v 固定穿透 |
| 法术 | `max(0.05A, 0.01A·max(0, 100 − (1−I_p)·max(0, D−I_v)))` | D=法抗（按百分比减伤） |
| 元素 | `max(0.05A, 0.01A·max(0, 100−D))` | D=元素抗性 |
| 真实 | `A` | 无视防御法抗，只被减伤/护盾影响 |
| 治疗 | `A` | 治疗也是一种“伤害类型” |

- **保底 5%**：物理/法术/元素伤害最低为基本伤害的 5%（不会完全归零）。
- 法抗是百分比：50 法抗 = 减伤 50%；100 法抗 = 只剩 5% 保底。
- 因此：**物理看攻击−防御的差值，法术看攻击×(1−法抗)**。高防敌人用物理会刮痧，高法抗敌人反之；真实伤害是万能解。
- 公式里的“倍率”（攻击力倍率/伤害倍率/治疗倍率）不是属性，同类倍率之间**相乘**（如 380% × 155%）。
- 攻速：`实际攻击间隔 T = T0 / (clamp(攻速,10,600)/100)`；攻速下限实际为 20。攻击间隔档位：非常快<0.8s，快 0.8–1.0，中等 1.0–1.2，较慢 1.2–1.6，慢≥1.6。
- 每秒攻击次数 = 1/T。攻速+100 = 间隔减半。

### 红字（Critical/暴击显示）
- 当最终伤害 ≥ **期望伤害×1.5** 时显示红字。期望伤害不计穿透、后置增益（脆弱等）、护盾、伤害重设、特殊生命值机制。
- 所以红字本质是“后置增益打出来的”，不是独立暴击系统。红字数值=最终伤害（就近取整），不影响实际结算。

## 3. 部署费用（DP）

- 关卡参数：初始费用（多数 10）、回复间隔（通常 1 秒/点）、上限（常规 99，剿灭类 999）、下限（通常 0）。
- 待部署区费用：`(初始部署费用 + 基础费用增减) × 费用倍率 + 实时费用增减`
  - 初始部署费用 = 面板费用（含精英化加费、潜能减费、模组减费）
  - 费用倍率通常只由**再部署惩罚**提供
- **再部署惩罚**：每次退场（撤退/被击倒）累积 1 层（上限 2 层），每层 +0.5 倍率 → 第二次部署 1.5 倍、第三次 2.0 倍（向下取整）。
- **撤退返费**：`⌊min(部署费用×返还倍率, 基础部署费用)⌋`
  - 常规 50%；先锋-冲锋手 100%；召唤物/装置/行商 0%
  - “无视返还上限”模组（CHG-X/EXE-X）才能返还该次全部费用
- 负数费用（可露希尔后）：可透支部署，回复到 0 前回费速度减半。

## 4. 索敌与仇恨（极重要）

**敌方仇恨优先级**：阻挡 → 特殊优先级 → 仇恨值（更容易被攻击 → 第二优先级 → 最后部署 → 不容易被攻击）→ 最早出现
**我方索敌优先级**：阻挡（近战限定）→ 特殊优先级 → 第二优先级 → 仇恨值（更容易被攻击 → 剩余路径最短 → 不容易被攻击）→ 最早出现

- 阻挡最优先：被阻挡的敌人会无视隐匿/无敌/不可选中，强行攻击阻挡它的干员。
- “最后部署的干员”只是一般规则：浮士德等超远射程（20格）等价于打全场最后部署者。
- 嘲讽等级：1 级约等于“部署极久”，用于拉仇恨（拜松、泡泡、夜莺幻影）；伏击客（水月/狮蝎）自带降嘲讽。
- 特殊索敌：神射手打最低防御；速射手优先空中；早露按重量；W 按生命值；苦艾按生命百分比。
- 前摇锁定：攻击前摇锁定的目标通常不会改变。
- 远程干员通常**不会**优先打自己被阻挡的敌人；近战干员会。
- 隐匿：不被敌方索敌选中；敌人被阻挡后解除，不被阻挡 3 秒后重新隐匿；反隐=给目标上反隐 buff。

## 6. 元素损伤（第五种“伤害”体系）

- 元素值 EP 默认 1000（领袖敌人 2000），默认不回复、损伤抵抗 0。
- 受到损伤 = 损伤值 ×(1−损伤抵抗%)；EP 归零 → **爆条**，触发爆发并进入冷却，冷却结束 EP 回满。
- 只用“当前损伤元素”（EP 最低者）显示与索敌；但实际爆发元素取决于首个施加的损伤。

| 元素 | 我方受爆发 | 敌方受爆发 |
|---|---|---|
| 神经 SANITY | 眩晕 10s + 1000 真实伤害 | 3 层麻痹 + 6000 元素伤害 |
| 侵蚀 WATER | 永久−100 防御 + 800 物理 | 8s，永久−120 防御（不可清除）+5000 元素 |
| 灼燃 FIRE | 法抗−20 + 1200 法术 | 法抗−20 + 7000 元素 |
| 凋亡 DARK | 15s 阻回+静默，每秒−1 技力 +100 法术 | 50% 虚弱递减 + 每秒 800 元素 |
| 狂躁 ANGER | 攻速+50，每秒受真实伤害（递增至 600） | 无效果 |

实战意义：元素损伤是**高防高法抗敌人的第三种解法**（爆条伤害按元素抗性算，通常敌人元素抗性低）；行医/元素系干员（如妮芙、塑心、缄默德克萨斯等）靠叠损伤打真伤。
