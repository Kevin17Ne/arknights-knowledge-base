# 战斗术语速查（读技能/配队必备）

> 来源：PRTS「术语释义」。同名效果大多“取最高”，不同名效果可叠乘——这是配队的核心逻辑。

## 1. 防御类（减伤体系）
| 术语 | 效果 | 关键点 |
|---|---|---|
| 屏障 | 吸收固定数值伤害，可吸全类型 | 屏障量≥伤害时该次攻击“被抵挡”；可被增伤顺序影响 |
| 护盾 | 每层抵挡**一次**伤害 | 与屏障不同：按次数不按数值 |
| 庇护 | 受到物/法伤害降低 X% | 同名取最高 |
| 伤害减免 | 受到伤害降低固定数值 | 极少见，同名取最高 |
| 闪避 | 概率完全躲避 | 多个闪避**叠乘** |
| 抵抗 | 晕眩/寒冷/冻结/恐惧/诱导等**持续时间减半** | 麻痹每 5 秒流失 1 层 |
| 坚忍 | 按已损失生命比例获得属性加成 | 线性增长，0.25s 更新 |
| 精力充沛 | 生命高于阈值时获得属性加成 | 0.1s 检查 |

## 2. 增伤/削防类
| 术语 | 效果 |
|---|---|
| 脆弱 | 受到物/法/真伤提升 X%（同名取最高）；另有物理脆弱/法术脆弱/元素脆弱分型 |
| 鼓舞 | 获得额外**基础属性**加成（最终加算，同类取最高倍率） |
| 术法充盈 | 造成的法术伤害提升（输出时作为伤害倍率） |
| 偷取 | 减目标属性加自身，双方都用最终加算，有上限 |
| 失重 | 重量下降 1 级（直接加算，同名取最高） |
| 虚弱 | 目标攻击力降低 X%（最终乘算，同名取最高） |

## 3. 控制类
| 术语 | 效果 |
|---|---|
| 停顿 | 移速 −80%（最终乘算，同名不叠加） |
| 束缚 | 无法移动 |
| 晕眩 | 无法移动/阻挡/攻击/技能 |
| 寒冷 | 攻速 −30；再受寒冷变冻结 |
| 冻结 | 无法移动/攻击/技能；**友方冻结**额外法抗 −15（敌方冻结不减抗） |
| 浮空 | 变空中单位，无法移动/攻击/技能；重量>3 持续减半 |
| 缚地 | 变地面单位、无法移动；让近地悬浮敌人掉落 |
| 战栗 | 被阻挡时无法普攻，可打断阻挡攻击 |
| 恐惧 | 无法被阻挡、四散逃跑（对角色类无效） |
| 诱导 | 无法被阻挡、向指定位置移动 |
| 麻痹 | 每层打断一次普攻，最多 3 层；有抵抗每 5 秒掉 1 层 |
| 沉睡 | 无敌 + 无法行动 + 不可阻挡 |
| 迷彩 | 不阻挡时不被普攻选中（躲不了溅射） |
| 隐匿 | 不阻挡时不被选中；阻挡即破隐，脱战 3 秒恢复 |
| 起飞 | 不挡地面、不被地面打、可挡飞行（对地规避） |
| 近地悬浮 | 变飞行、不可阻挡；**仍走地面寻路** |

## 4. 技能机制类
| 术语 | 含义 |
|---|---|
| 蓄力 | 技力可回复到 2 倍上限，开技能触发额外效果 |
| 过载 | 技能分两段，进行到一半触发强化（持续条变红不倒退） |
| 魔力 | 特殊技力，整场继承，入场转技力、退场转魔力 |
| 吟唱 | 停止攻击一段时间后开技能，期间被打断则中止 |
| 绑定 | 绑定对象不在场则技能强制结束、清空技力 |
| 补弹 | 为他人弹药技能补弹（上限为本次弹药数） |
| 装备应变 | 选中在场干员后可激活的额外效果（佣兵分支等） |
| Fever | Ave Mujica 联动专属：450 点后全队 20 秒无视技力持续开技能 |

## 5. 元素
- 元素损伤五类：神经（眩晕+真伤）、侵蚀（永久削防）、灼燃（减 20 法抗+法伤）、凋亡（阻回+静默）、狂躁（攻速+50 但持续真伤）。
- 元素值默认 1000（领袖 2000），爆条后进入冷却、冷却结束回满。

## 6. 配队口诀
1. **减伤看“名”**：庇护/屏障/护盾/闪避是不同名，能叠；同名的只取最高，别带两个同款。
2. **增伤要分层**：攻击力%（直接乘算）、伤害%（脆弱）、最终倍率（攻击力提升至 X%）乘起来才爆炸。
3. **控制要配套**：冻结减抗 15，所以“冻结+法伤”是经典组合；浮空/战栗能废掉敌人普攻。
4. **抵抗是软解**：把晕眩/冻结时间减半，比硬免更通用。
