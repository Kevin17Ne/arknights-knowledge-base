# 领袖/精英敌人：怎么读数据、怎么配对策

> 配套文件：`05-攻略与meta/04-领袖敌人索引.md`（238 个领袖全表，自动生成）
> 本地工具：`node tools/enemy.js <关键词> [等级]`，例：`node tools/enemy.js 霜星`、`node tools/enemy.js 萨卡兹 领袖`

## 1. 数据集概况（PRTS 敌人一览/数据）
- 全 1737 条敌人：**普通 765 / 精英 734 / 领袖 238**
- 领袖种族分布：其他 144、萨卡兹 23、化物 22、海怪 11、感染生物 9、机械 8、法术造物 6、坍缩体 5、源石造物 4、野生动物 4、无人机 2
- 每条含：伤害类型（物理/法术/无）、行动方式（地面/飞行）、攻击/防御/法抗/耐久评级（S>A+>A>B+>B>C>D>E）

## 2. 评级怎么用
| 评级 | 含义 | 打法含义 |
|---|---|---|
| 防 S/A | 极高防御 | 物理基本打不动 → 法伤/真伤/削防 |
| 抗 S/A | 极高法抗 | 法术减伤严重 → 物理/真伤/削抗 |
| 攻 S/A | 高攻击 | 需要高阻挡+奶，或控住再杀 |
| 血 S/A+ | 超高耐久 | 需要爆发窗口/多轮输出 |
| 移速 A | 跑得快 | 提前布防、推拉/减速 |

## 3. 按“伤害类型”配队
- **物理型领袖**：堆防御/闪避/护盾；输出用高攻物理或法伤（看它法抗）。
- **法术型领袖**：堆法抗/屏障；输出用物理（看它防御）。
- **无类型（真实伤害）**：只能靠血量、减伤、控制、快速击杀。
- 两者都高（防 S + 抗 S）：**真实伤害 / 元素爆条 / 削防削抗**才是答案。

## 4. 常见领袖原型与对策
| 原型 | 特征 | 对策 |
|---|---|---|
| 高防重甲 | 防 S/A，走得慢 | 法伤、真伤、削防（初雪/黑键类）、推拉拖时间 |
| 高法抗法师 | 抗 S/A，远程法术 | 物理狙/近卫、削抗、沉默 |
| 高速突击 | 移速 A/S，直冲终点 | 提前阻挡、减速、眩晕/冻结、推拉 |
| 召唤/分裂 | 不断产生小怪 | 群攻、AOE、优先斩首本体 |
| 全图/超远射程 | 打最远/最后部署 | 调整部署顺序、用高台诱饵、快杀 |
| 护盾/屏障 | 有额外血条 | 先破盾再爆发；注意伤害加成与屏障结算顺序 |
| 复活/多阶段 | 死后变强/回血 | 留爆发技能给二阶段，别一波打空 |
| 控制型 | 眩晕/冻结/恐惧 | 抵抗、解控、远程消耗 |

## 5. 几个标志性领袖（记忆锚点）
- **霜星 / 霜星“冬痕”**：法术型、抗 A、血 A+；核心威胁是**冻结**与大范围冰系攻击，需要抗冻/远程消耗/快速击杀。
- **爱国者**：两形态（行军→毁灭），高防高血；毁灭形态会攻击最远的高台干员，并带嘲讽——需要削防/法伤/真伤与站位设计。
- **塔露拉**：火系大范围法术，全屏火雨类技能；靠法抗、位移与爆发窗口。
- **浮士德**：超远射程（约 20 格），等价于“专打你最后部署的人”；用部署顺序与诱饵处理。
- **弑君者**：高频闪现/瞬移，难以锁定；用真伤、范围伤害、预判位置。
- **泥岩（敌方）**：高防 + 屏障，物理刮痧；法伤/真伤/先破盾。
- **大鲍勃 / 大亚当**：早期高攻高防代表，教玩家“物理打不动就换法伤”。

## 6. 打领袖的通用流程
1. 查数据（`tools/enemy.js`）→ 确认伤害类型、防/抗/血/移速。
2. 算输出：需要多少攻击、几次技能、要不要拐/削防。
3. 设计阻挡与奶：领袖攻 S 时，阻挡位要能扛住 2~3 下。
4. 留爆发给二阶段/破盾后。
5. 处理召唤物与小怪，别让领袖带着一群杂兵进点。
