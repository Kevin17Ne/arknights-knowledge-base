# 实战诊断清单（卡关时按这个顺序查）

> 目标：不靠“感觉”调队，而是按机制逐项排查。

## 1. 先读敌人面板（点敌人看情报）
逐项确认：
1. **生命 / 防御 / 法抗 / 元素抗性**：防御 ≥ 我方物理攻击一半 → 物理刮痧，换法伤/真伤/穿透；法抗 ≥ 50 → 法伤减半。
2. **重量**：决定能不能推/拉（力度−重量表：差值 0 推 1.7 格，≤−3 推不动）。
3. **攻击方式**：近战/远程、单体/溅射、是否打高台、射程多少。
4. **移动速度与路线**：决定你需要在哪一格拦截。
5. **特殊能力**：隐身、飞行、分裂、召唤、复活、护盾、反伤、治疗、光环、自爆、传送、禁疗、减费、毒雾。
6. **是否精英/领袖**：精英与领袖通常有抗性、元素值 2000、阶段性强化。

## 2. 伤害够不够（心算）
- 物理：`(攻击×倍率 − 防御) × 命中次数`，保底 5%。
- 法术：`攻击 × (1 − 法抗/100)`，保底 5%。
- 需要打死一个 H 血、D 防的敌人：`所需攻击 ≈ (H / 命中次数) + D`。
- 打不动就三条路：**加攻（拐）> 削防/削抗（debuff）> 换伤害类型（真伤/元素）**。
- 元素：EP 1000（领袖 2000），先算要几次爆条；爆条伤害按元素抗性算，通常比物理/法术好打。

## 3. 常见死因对照表
| 现象 | 最可能原因 | 解法 |
|---|---|---|
| 干员瞬间被秒 | 高攻远程/溅射/法伤 | 换位置、加奶、上护盾/庇护、先手控 |
| 漏怪 | 阻挡数不够 / 输出不足 / 路线没堵 | 加阻挡、补输出、卡位 |
| 费用不够 | 先锋太弱/被限制 | 双先锋、执旗手、费用回复干员 |
| 奶不起来 | 单次伤害过高 / 禁疗 | 群奶、护盾、减伤、秒掉威胁 |
| 输出为 0 | 高防/高法抗/无敌/闪避 | 换伤害类型、穿透、真伤、无视闪避 |
| 技能放不出来 | 技力被阻回/静默/眩晕 | 换干员、解控、提前开技能 |
| 高台被打 | 敌人打高台/溅射 | 换地面位、加射程外输出 |
| 干员被推/拉 | 敌人位移 | 重量、阻挡、远程解决 |

## 4. 阵容调整决策树
1. **先确认“这关的胜利条件”**：漏几个算输？有没有时间限制？保护目标？
2. **找“必须处理的机制”**：飞行？隐身？护盾？复活？元素？——每个机制配一张对策卡。
3. **算部署位**：地面几个、高台几个；不够就换“一专多能”干员（奶盾、召唤、能打能拐）。
4. **排轴**：先下谁（先锋）→ 核心输出 → 奶 → 对策；技能轴按敌人波次对齐。
5. **最后才堆练度**：机制不对，练度再高也打不过。

## 5. 抄作业注意事项
- 先看**干员替代性**：作业里的核心干员能不能用同分支替代（看阻挡数、攻击间隔、技能机制）。
- 注意**潜能/模组/专精差异**：差一点攻击可能导致漏怪。
- 注意**代理稳定性**：随机索敌、暴击、闪避、帧数都会导致代理失败；要稳定代理就减少“看脸”环节。
- 活动关的代理失败常见于：波次时间偏移、击杀顺序变化、技能轴错位。
