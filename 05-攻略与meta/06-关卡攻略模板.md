# 关卡攻略模板（可复用）

> 工具：`node tools/stage.js "7-18"` 直接抓取关卡基础数据与敌人列表
> 用法：拿到任何关卡，按下面 7 步填表，就能得出打法方向。

## 第 1 步：读关卡基础数据
| 字段 | 影响 |
|---|---|
| 地图大小 | 决定射程覆盖、绕路空间 |
| 部署上限 | 决定能带几个输出/奶/对策 |
| 初始 COST / COST 上限 | 决定开局节奏（10 费开局=先下先锋） |
| 目标点耐久 | 允许漏几个（耐久 1 就是零容错） |
| 敌人数量 | 估算总输出量与技能次数 |
| 作战消耗 | 决定试错成本 |
| 特殊地形/装置 | 关卡的核心解法往往在这里 |
| 突袭条件 | 附加限制（禁用格子、敌人强化） |

## 第 2 步：读敌人表
- 数量最多的杂兵 = 清线压力；数量 1~2 的精英/领袖 = 机制核心。
- 对照 `tools/enemy.js` 查它们的防御/法抗/重量/伤害类型，决定输出类型。

## 第 3 步：读关卡描述
官方描述里的每个 `<装置>` 都是解题钥匙：
- 增伤/减防类装置 → 找爆发窗口
- 治疗/护盾类 → 找续航点
- 位移/陷阱类 → 找地形杀
- 环境伤害（毒雾、祭坛、涨潮）→ 决定站位与奶量

## 第 4 步：定胜利条件
漏几个算输？有没有时间限制？有没有必须保护的目标/装置？有没有“必须击杀”的敌人？

## 第 5 步：选阵容（按职能配）
- 产费 1~2（先锋）
- 地面承伤 1~2（重装/近卫）
- 高台输出 2~3（狙击/术师，按敌人防/抗选）
- 治疗 1~2（单奶+群奶）
- 对策 1~2（元素/推拉/快活/沉默/真伤）
- 剩余位置给“能兼顾两项”的干员

## 第 6 步：排轴
1. 开局：先锋 → 费用够了下核心输出
2. 中期：按波次开技能，别空放
3. 高压波：留控制/爆发/地雷
4. 领袖：先破盾/削防，再进增伤窗口爆发
5. 收尾：处理漏网小怪，注意别让技能进入 CD 空窗

## 第 7 步：验证
- 代理稳定性：有没有随机索敌/闪避/暴击导致的轴偏移
- 容错：奶量、阻挡数、费用是否都有冗余
- 失败复盘：对照 `05-攻略与meta/03-实战诊断清单.md`

## 示例：7-18「爱国者之死」
**数据**（工具实抓）：主线难关｜推荐精二 30｜部署 9｜初始 10 费｜耐久 3｜敌人 45｜地图 12×8｜消耗 21 理智
**机制**：
- **源石祭坛**：周期性对周围释放脉冲波，**敌我双方都受伤** → 站位要避开祭坛范围，或用法抗/高血单位硬吃
- **干扰地雷**（我方装置 15 个）：爆炸造成大量伤害，并使敌人 **15 秒内受到的伤害增加** → 这是全关的核心爆发窗口
**敌人**：游击队猎犬×4、战士×16、狙击手×4、迫击炮兵×2、突袭战士×11、突袭战士组长×2、萨卡兹战士×5、**爱国者×1**
**突袭**：6 个格子不可部署 + 敌人生命 120%、攻击 110%

**打法要点**：
1. 爱国者是双形态领袖：一阶段高防，物理刮痧 → 用法伤/真伤/削防；二阶段攻击性大幅提升，会威胁高台 → 高台位置要提前规划
2. **地雷是伤害放大器**：把主力爆发技能对齐“地雷爆炸后的 15 秒”，而不是见面就开
3. 3 点耐久 = 最多漏 3 个，杂兵波次必须有人守
4. 祭坛会持续消耗我方血量 → 群奶或高法抗单位更稳
5. 突袭禁用 6 格后，站位空间被压缩，优先保住“主输出 + 主奶”两处

> 结论：这关考的是**爆发窗口管理**（地雷）+ **双形态应对**（物法切换）+ **站位避祭坛**，不是纯练度。
