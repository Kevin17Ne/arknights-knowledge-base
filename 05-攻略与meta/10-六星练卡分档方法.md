# 六星练卡分档方法（数据 + 环境）

> 不搞“拍脑袋 T0 榜”，用可核查的四步给六星定档；末尾附社区共识参考。
> 数据来源：`stats_6star.json`、`skills_6star.json`、`modules_6star.json`、分支标签（`tools/box.js`）

## 第 1 步：稀缺度（补不补缺口）
先跑 `node tools/box.js <你的干员...>`：
- 补上 dp/heal/tank/arts/element 中**任一缺口** → +1 档
- 职能与现有干员完全重复 → −1 档

## 第 2 步：面板（同分支对比）
- 攻击/生命/防御是否在**同分支前列**（`02-干员/07-六星面板数据.md`）
- 注意攻击间隔：面板高但间隔 2.5s 的重剑手，实际 DPS 未必高
- 部署费用：低费高面板是稀缺资源

## 第 3 步：技能（有没有质变）
| 信号 | 加分 |
|---|---|
| 无限持续 / 弹药 / 可主动关闭 | +（上限取决于操作） |
| 低消耗（≤20）+ 短 CD | +（循环稳定） |
| 自带回费/回血/减伤/控制 | +（一专多能） |
| 纯数值倍率、无机制 | 中性 |
| 需要苛刻条件才生效 | − |

用 `node tools/skilldb.js <干员>` 看 M3 的初始/消耗/持续。

## 第 4 步：模组（改不改天赋）
- 模组 2/3 级**新增效果/改倍率/改范围** → +1 档
- 只加属性 → 中性
- 查 `02-干员/09-模组效果速查.md`

### 第二档：强力对策/体系件（按需练）
- 元素：克莱门莎、真言、烛煌、余、珊比、纯烬艾雅法拉
- 控制：安洁莉娜、铃兰、多萝西、望、溯光星源
- 对空/远程：能天使、空弦、假日威龙陈、予愿安洁莉娜
- 快速复活：傀影、缄默德克萨斯、麒麟R夜刀、弑君者
- 位移：温蒂、歌蕾蒂娅
- 召唤：麦哲伦、电弧

### 第三档：特化/厨力（资源富余再练）
- 仅在特定机制关有发挥、或定位被同分支上位覆盖的干员
- 判断方法：第 1 步“职能重复”且第 3 步“无机制质变”

## 单卡评估模板（例：维什戴尔）
1. 稀缺度：box 缺高台物理 → +1
2. 面板：投掷手攻击 687、间隔 2.1s，同分支中上
3. 技能：S3 弹药 6 发、攻击 +180%/单次 220%、天赋 100%、溅射扩大 → 质变
4. 模组：以属性/天赋强化为主 → 中性
→ 结论：第一档，优先精二 60 + S3 专三。

## 重要提醒
- 档位是**环境快照**：新干员/新模组/新合约会改变排序（尤其 11-01 塔露拉上线后）。
- “第一档”不等于“必须抽”：如果 box 已有同职能替代，优先级下降。
- 面板/技能数据可查，**环境判断**要看当期活动与合约，这部分要持续更新。
