# 低配与新手打法（3~4★ 也能过图）

> 适用：box 不全、主线推进、活动低配作业、集成战略低难。
> 核心思想：**靠机制和站位，不靠数值**。

## 1. 低配队的标准骨架
| 职能 | 推荐（3~4★） |
|---|---|
| 产费 | 芬、香草、翎羽、讯使、清道夫 |
| 阻挡/承伤 | 米格鲁、卡缇、蛇屠箱、角峰 |
| 地面输出 | 玫兰莎、缠丸、慕斯、杜宾 |
| 高台物理 | 克洛丝、流星、白雪、杰西卡 |
| 高台法术 | 炎熔、史都华德、阿米娅 |
| 治疗 | 芙蓉、安赛尔、末药、调香师（群奶）、苏苏洛 |
| 功能 | 梓兰（减速）、暗索/崖心（拉）、砾（快速复活） |

## 2. 低配为什么能过图
1. **部署费用低**：同样的费用能多下一个单位，容错反而高。
2. **再部署快**：可以反复换位救场。
3. **三星免素材晋升**：任务奖励直接给晋升材料，成型快。
4. **机制不吃数值**：推拉、阻挡偏移、卡位、地形杀，与攻击力无关。

## 3. 核心技巧
- **卡位/阻挡偏移**：把干员下在敌人格子上，敌人会被推到半径 0.5 的圆边界，能改变它的行进路线。
- **阻挡数管理**：低配盾阻挡 2~3，别让两条路的敌人同时压上来；用“下一个人挡住”的方式接力。
- **技能时机**：低配输出靠技能倍率，技能空窗期就是漏怪期，要算好波次。
- **演习**：普通关演习消耗 1、突袭 3，不耗理智不掉落，先演习再实战。
- **借干员**：助战可以借一个高练度核心（注意：剿灭 400 击杀要求“无助战”）。
- **地形杀**：坑、传送、源石祭坛、地雷，都是低配的“免费输出”。

## 4. 常见关卡类型的低配解法
| 类型 | 解法 |
|---|---|
| 单路推进 | 双先锋开局 → 盾+输出堵门 → 奶跟上 |
| 双路分推 | 一路低成本拖延（砾/减速），一路主力 |
| 空中单位 | 速射手优先，地面用对空近卫/术师补 |
| 高防精英 | 法术输出 + 削防（初雪类低星没有就靠法伤） |
| 领袖 | 地雷/装置增伤窗口 + 技能爆发，别硬拼面板 |
| 长线剿灭 | 挂机阵型，阻挡够、奶够、技能自动 |

## 5. 新手资源顺序
1. 3★ 先遣队 → 推主线到 4-9
2. 基建（0-11 解锁）→ 越早越好
3. 抽到的高星核心精二（1~2 个）
4. 补关键 4★（桃金娘、蛇屠箱、调香师、讯使）
5. 再考虑专精/模组

## 6. 心态
- 低配作业的价值是“理解机制”，不是“抄坐标”。
- 打不过先看敌人面板和关卡装置，再想“哪个机制没用到”。
- 练度是最后手段：机制对了，3★ 也能过 7 章前。
