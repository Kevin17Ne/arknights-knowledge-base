# 账号体检流程（给任何 box 做诊断）

> 用途：你发干员列表/截图，我按这套流程输出“练谁、抽谁、先干嘛”。
> 原则：**补职能缺口 > 追强度 > 厨力**。

## 第 0 步：收集信息（缺一项就少一分准确）
1. **六星列表**（有练度最好：精二？专三？模组？）
2. **关键低星**：桃金娘、讯使、玫兰莎、克洛丝、蛇屠箱、苏苏洛、调香师、阿米娅（这些决定开荒能力）
3. **主线进度**：推到第几章（决定能刷什么材料、解锁哪些模式）
4. **资源库存**：龙门币、经验、技巧概要、玉/黄票、模组材料
5. **目标**：推主线 / 打活动 / 合约冲分 / 集成战略 / 单纯收集

## 第 1 步：职能覆盖检查（逐项打勾）
| 职能 | 是否覆盖 | 判断标准 |
|---|---|---|
| 产费 | ☐ | 有 1~2 个稳定回费先锋（桃金娘/讯使/凛御银灰…） |
| 地面承伤 | ☐ | 有能扛领袖 2~3 下的重装/近卫 |
| 地面输出 | ☐ | 有能单守一路的近卫 |
| 高台物理 | ☐ | 对空速射 + 打高甲手段 |
| 高台法术 | ☐ | 群法 + 单体法 |
| 治疗 | ☐ | 单奶 + 群奶（奶盾更好） |
| 元素/真伤 | ☐ | 打高防高抗的“第三解法” |
| 控场 | ☐ | 减速/眩晕/冻结/沉默至少 2 种 |
| 快活/位移 | ☐ | 处决者、推拉、陷阱 |
> 缺 3 项以上 = 先补职能，别追新卡。

## 第 2 步：账号类型诊断
| 类型 | 特征 | 优先级 |
|---|---|---|
| 萌新（主线 < 4-9） | 干员少、练度低 | 3~4★ 先遣队 → 推主线 → 基建 |
| 中期（4-9 ~ 主线最新） | 有一队精一/少量精二 | 补核心精二 → 打活动 → 攒资源 |
| 长草期 | 主线通、活动能打 | 专三核心、开模组、合约/肉鸽 |
| 回归 | 缺版本新卡 | 先补“环境核心”，再补对策 |
| 合约向 | 干员池深 | 对策卡 + 模组 + 轴 |

## 第 3 步：练卡决策算法
1. **能不能补上第 1 步的空缺？** 能 → 最高优先。
2. **是不是泛用核心？**（能进多数队伍）→ 次优先。
3. **是不是当前活动的解法卡？** → 活动期间临时优先。
4. **厨力** → 最后。
- 练度目标：精二 60 级、核心技能专三、关键模组 1~3 级。
- 资源纪律：一次只练 1~2 个，练完再开下一个。

## 第 4 步：抽卡决策树
1. 是不是**限定**？（限定不復刻，优先级最高）
2. 是不是**泛用核心**（能替代你缺的职能）？
3. 是不是**当前高难的对策卡**？
4. 玉够不够 200 抽？不够就“捞到即停”，别垫。
5. 常驻池只在“双 UP 都需要”时抽；黄票留给 180 换六星。

## 第 5 步：输出模板（我会按这个格式回你）
```
【诊断】账号类型 + 最大短板（1~2 条）
【本周】最该做的 3 件事（推图/刷材料/练谁）
【30 天】精二/专三/模组清单 + 目标关卡
【90 天】抽卡规划（攒多少、抽哪个池）
【不要做】当前最浪费资源的行为
```

## 第 6 步：常见误诊
- “六星多就一定强”：职能重复的六星不如一个对口的五星。
- “先练输出”：没有产费和奶，输出根本站不住。
- “活动期间练新卡”：活动期应该刷代币，练卡留到长草期。
- “平均专精”：5 个 M1 不如 1 个 M3。
- “忽视基建”：基建是唯一 24 小时产出的系统，早建早回本。
