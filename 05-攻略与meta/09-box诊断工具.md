# box 诊断工具与用法

> 工具：`node tools/box.js <干员1> <干员2> ...`
> 配套：[账号体检流程](07-账号体检流程.md)｜[分支干员图鉴](../02-干员/02-分支干员图鉴.md)

## 1. 它做什么
输入你有的干员（名字即可，支持 3~6★），输出：
1. 每名干员的职业-分支与**职能标签**（dp/承伤/物理/法术/治疗/控制/元素/对空/位移/快活）
2. 十项职能的**覆盖情况**（✓/✗）
3. **缺口清单**
4. 针对每个缺口，从六星池里列出**可补位的干员**（按分支标签匹配）

## 2. 示例
```sh
node tools/box.js 维什戴尔 黍 桃金娘 史尔特尔 能天使
```
输出：
```
职能覆盖：
  ✓ dp: 桃金娘      ✓ tank: 黍        ✓ phys: 维什戴尔、能天使
  ✓ arts: 史尔特尔  ✓ heal: 黍        ✓ anti_air: 能天使
  ✗ control / element / shift / fast
缺口：control、element、shift、fast
可用六星补充：安洁莉娜/铃兰（控制）、酒神/塑心（元素）、温蒂/歌蕾蒂娅（位移）、傀影/缄默德克萨斯（快活）
```

## 3. 标签体系（分支 → 职能）
| 标签 | 含义 | 典型分支 |
|---|---|---|
| dp | 产费 | 尖兵/执旗手/策士/冲锋手 |
| tank | 承伤 | 铁卫/守护者/不屈者 |
| phys | 物理输出 | 强攻手/领主/速射手/投掷手 |
| arts | 法术输出 | 术战者/扩散术师/中坚术师 |
| heal | 治疗 | 医师/群愈师/吟游者 |
| control | 控制 | 凝滞师/链术师/陷阱师 |
| element | 元素 | 巫役/本源三系/行医 |
| anti_air | 对空 | 速射手/裂空炮手 |
| shift | 位移 | 推击手/钩索师 |
| fast | 快速复活 | 处决者 |

## 4. 判读规则
- **缺 dp / heal / tank 任意两项**：先补基础，别碰高难。
- **缺 arts 或 element**：遇到高防敌人会很难受，优先补一个法术核心或元素件。
- **缺 control / shift / fast**：不是硬性，但高难和剿灭会很吃力。
- 标签只是“分支级”判断，具体干员强度要看技能与面板（用 `skilldb.js` / `dmg.js`）。

## 5. 下一步（人工）
工具给的是“覆盖面”，真正的诊断还要看：
1. 练度（精二/专三/模组）
2. 主线进度与可刷材料
3. 目标（活动/合约/肉鸽）
4. 资源库存
把这几项和 box 输出一起给我，就能出《账号体检报告》。
