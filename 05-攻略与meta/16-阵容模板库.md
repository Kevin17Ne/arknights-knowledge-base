# 阵容模板库（10 套配队范式）

> 把机制知识合成配队能力。每套给：核心思路 / 必备职能 / 代表干员（多为实查数据） / 适用 / 弱点。
> 代表干员来自本地技能库筛选（`skilldb.js`），可自行替换。

## 1. 单核爆发（保核流）
- **核心**：一个主 C 吃满所有拐，在窗口期打一波。
- **必备**：产费 2、主 C、拐（鼓舞/脆弱/削防）、控制、奶。
- **代表**：玛恩纳（解放者，蓄力核弹）、史尔特尔（法伤爆发）、维什戴尔（弹药爆发）。
- **适用**：领袖关、高防精英、合约顶层。
- **弱点**：主 C 被控/被秒就崩；轴错一步全盘皆输。

## 2. 双核轮转
- **核心**：两个输出交替开技能，覆盖技能空窗。
- **必备**：产费 2、双输出（一物一法更稳）、奶、阻挡。
- **代表**：银灰 + 艾雅法拉、维什戴尔 + 逻各斯。
- **适用**：长线（剿灭、生息演算）、多波次活动。
- **弱点**：费用压力大，部署位紧张。

## 3. 挂机/分奴
- **核心**：自动触发技能 + 高阻挡 + 稳定奶，追求代理 100% 稳定。
- **必备**：自动技能输出、奶盾/群奶、阻挡 3 的重装。
- **代表**：能天使（自动）、塞雷娅/黍（奶盾）、星熊/年（铁卫）。
- **适用**：剿灭、日常刷图、活动挂机。
- **弱点**：上限低，高难打不动。

## 4. 低配开荒
- **核心**：3~4★ 低费多下，靠机制与站位。
- **必备**：芬/讯使（产费）、米格鲁/蛇屠箱（阻挡）、克洛丝/流星（对空）、炎熔/史都华德（法伤）、芙蓉/调香师（奶）。
- **适用**：主线前 4 章、活动低配作业。
- **弱点**：数值上限低，后期必须换核。

## 5. 元素爆条
- **核心**：叠元素损伤 → 爆条打真伤式伤害，专治高防高抗。
- **必备**：元素输出（本源/巫役）+ 行医/元素辅助 + 阻挡。
- **代表（实查技能含元素伤害）**：妮芙、烛煌、真言、克莱门莎、折光、温米、聆音、Miss.Christine；巫役：酒神、塑心。
- **适用**：双抗领袖、合约高难、高防精英。
- **弱点**：需要时间叠条；敌人有元素抗性/免疫时失效。

## 6. 召唤/多线
- **核心**：用召唤物/战术点/陷阱同时处理多路。
- **必备**：召唤师/战术家/陷阱师 + 本体输出。
- **代表**：麦哲伦（召唤师）、电弧、多萝西（陷阱师）、望（陷阱师）、可露希尔（战术家）。
- **适用**：多路漏怪、需要“多一个阻挡”的图。
- **弱点**：操作量大，召唤物占部署位/费用。

## 7. 推拉位移
- **核心**：把敌人推下坑/推回起点/拉进火力区。
- **必备**：推击手/钩索师 + 地形（坑/窄道）。
- **代表**：温蒂（推击手）、歌蕾蒂娅（钩索师）、崖心/暗索（4~5★ 钩索）。
- **适用**：有坑/窄道的地图、部分活动机制关。
- **弱点**：依赖地形；重量 ≥5 的敌人推不动。

## 8. 法蒸（削抗 + 法伤）
- **核心**：先削法抗，再让法伤干员爆发。
- **必备**：削弱者（初雪/灵知）+ 法伤核心 + 控制。
- **代表**：初雪、灵知（削弱者）、艾雅法拉/逻各斯（法伤）。
- **适用**：高法抗敌人、法伤体系。
- **弱点**：遇到高法抗+高防双高时仍需真伤/元素。

## 9. 真伤斩杀
- **核心**：无视防御法抗，直接打真实伤害。
- **代表（实查技能含真实伤害）**：温蒂、浊心斯卡蒂、耀骑士临光、玛恩纳、赫德雷、魔王、维娜·维多利亚、凯尔希·思衡托、夜魔。
- **适用**：双抗怪、护盾怪、机制型领袖。
- **弱点**：真伤干员稀缺、倍率有限，通常需要控制配合。

## 10. 速攻/开局压制
- **核心**：低费高机动单位快速清前期、切后排、抢节奏。
- **代表**：情报官（伊内丝/晓歌）、冲锋手（风笛）、处决者（傀影/缄默德克萨斯/麒麟R夜刀）。
- **适用**：开局高压、需要切术师/狙击的图。
- **弱点**：后期乏力，吃操作。

## 选模板的判断顺序
1. 敌人是**高防**还是**高抗**？→ 决定法蒸/物理/真伤/元素
2. 有没有**必须处理的机制**（飞行/护盾/召唤/位移）？→ 决定对策位
3. 关卡是**长线**还是**爆发窗口**？→ 决定双核/单核/挂机
4. 部署位够不够？→ 决定召唤/多线是否可行
5. 最后才考虑“我想玩什么”
