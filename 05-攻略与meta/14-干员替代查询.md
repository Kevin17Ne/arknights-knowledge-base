# 干员替代查询（抄作业/补位用）

> 工具：`node tools/alt.js <干员>`
> 数据：407 名干员面板库（分支/攻击/生命/费用/阻挡/间隔）

## 1. 它做什么
输入一个干员，输出**同分支的所有其他干员**，按攻击力排序，并显示星级、生命、费用、阻挡。
用于：
- 抄作业时找“同定位替代”
- box 缺某干员时找“最接近的替补”
- 判断某个分支的强度梯度

示例：
```sh
node tools/alt.js 银灰
# 银灰（近卫-领主）攻击713 费用18→20 间隔1.3s
# 同分支：丰川祥子[6★]725、仇白[6★]718、棘刺[6★]711、罗小黑[4★]698、拉普兰德[5★]685…
```

## 2. 替代的判断顺序
1. **同分支**（特性相同：阻挡/攻击方式/范围逻辑）——最接近
2. **同职业同职能**（跨分支：如速射手↔投掷手都能对空，但机制不同）
3. **同职能跨职业**（如用术师替代法伤近卫）
逐一检查：
| 检查项 | 为什么 |
|---|---|
| 阻挡数 | 阻挡 1 vs 2/3 直接影响能不能堵路 |
| 攻击间隔 | 面板高但间隔长，DPS 可能更低 |
| 部署费用 | 费用差 3 点以上会打乱开局轴 |
| 技能机制 | 倍率、范围、持续、SP 消耗是否同型 |
| 天赋/模组 | 光环/减费/控制等队伍级效果无法替代 |

## 3. 常见替代关系（示例）
| 原干员 | 同分支替补 | 备注 |
|---|---|---|
| 银灰 | 棘刺、拉普兰德、丰川祥子 | 领主远程白嫖，注意技能范围差异 |
| 能天使 | 蓝毒、灰烬、空弦 | 速射手对空，连射/暴击机制不同 |
| 桃金娘 | 极境、琴柳、万顷 | 执旗手产费，费用与回费效率不同 |
| 蛇屠箱 | 米格鲁、角峰 | 4★ 重装，阻挡与防御接近 |
| 史尔特尔 | 赤刃明霄陈、星极 | 术战者法伤，爆发窗口不同 |

## 4. 注意
- **同分支 ≠ 可无脑替代**：分支只保证“特性一致”，技能与天赋才是强度来源。
- 高星替代低星通常更强，但**费用更高**，低配作业里反而可能打乱轴。
- 替代后要重新算：`node tools/dmg.js` 验伤害、`node tools/skilldb.js` 看技能。
- 若替代干员的技能是“手动触发”，而原作业是“自动触发”，轴会完全不同。
