# 练卡优先级与分支取舍

> 配合 `02-干员/02-分支干员图鉴.md`（72 分支 / 226 名代表干员）阅读。
> 原则：**先补职能缺口，再追强度**；同职能只练最强的 1~2 个。

## 1. 每个职业“必须有”的职能
| 职业 | 必须覆盖的职能 | 代表分支 |
|---|---|---|
| 先锋 | 开局产费（至少 1 个稳定回费） | 尖兵/执旗手/策士 |
| 近卫 | 地面持续输出 + 单切爆发 | 领主/强攻手/术战者/解放者 |
| 重装 | 高阻挡承伤 + 奶盾 | 铁卫/守护者/不屈者 |
| 狙击 | 对空速射 + 高甲攻坚 | 速射手/神射手/投掷手 |
| 术师 | 群体法术 + 单体爆发 | 扩散术师/中坚术师/轰击术师 |
| 医疗 | 单体奶 + 群体奶（+元素奶） | 医师/群愈师/行医 |
| 辅助 | 减速/增伤/召唤 | 凝滞师/吟游者/召唤师 |
| 特种 | 快速复活 + 位移/陷阱 | 处决者/推击手/钩索师/陷阱师 |

## 2. 优先级排序（通用）
1. **产费先锋**（没有费用什么都干不了）
2. **泛用地面核心**（能扛能打的近卫/重装）
3. **泛用高台输出**（狙击/术师各一）
4. **医疗**（单奶+群奶）
5. **对策卡**：元素（巫役/行医/本源系）、推拉、快速复活、沉默/冻结、真实伤害
6. **厨力/杂技**

## 3. 分支取舍经验
- **先锋**：尖兵万金油；执旗手（桃金娘）产费效率最高；策士（凛御银灰）兼顾支援待部署区；情报官（伊内丝）游走回费+隐匿交互。
- **近卫**：领主（银灰/拉普兰德）远程白嫖；强攻手（煌）清杂；术战者（史尔特尔）法伤爆发；解放者（玛恩纳/司霆惊蛰）蓄力核弹；收割者（隐德来希）自回血单带。
- **重装**：铁卫纯扛；守护者（塞雷娅/黍）奶盾一体最保值；不屈者（泥岩）单守一路；驭法铁卫（斩业星熊）技能期法伤。
- **狙击**：速射手（能天使）对空；神射手（黑/蕾缪安）打高防；投掷手（维什戴尔）多段余震；攻城手（早露）打重甲。
- **术师**：扩散（伊芙利特）烧一路；中坚（艾雅法拉）单体；轰击（谬因）超远群伤；阵法（圣聆初雪）常态不攻击但极硬；驭械（荒芜拉普兰德）浮游单元。
- **医疗**：医师（闪灵）单奶；群愈（夜莺）群奶+法抗；行医（蜜莓/桑葚）解元素；链愈（Mon3tr）跳跃奶。
- **辅助**：凝滞（安洁莉娜/溯光星源）减速；吟游者（浊心斯卡蒂）光环；召唤（麦哲伦/电弧）多线；巫役（酒神）元素。
- **特种**：处决者（傀影/缄默德克萨斯）快速复活；推击手/钩索师打位移；陷阱师（多萝西/望）控场；伏击客（水月/国度）地雷+闪避。

## 4. 资源分配纪律
- 一个干员通常只专精 **1 个核心技能**，专三前先看“是否质变”。
- 模组优先开“改机制/改范围”的；纯数值模组等卡阈值再开。
- 六星精二 60 级封顶性价比；真爱/主 C 再上 90。
- 三四星别全弃：低费、低养成成本，在集成战略和部署受限图里是主力。
- 每抽到新六星，先问“它替掉了谁”，再决定练不练。
