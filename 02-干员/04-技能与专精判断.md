# 技能机制与专精判断

> 读技能看四件事：**技力怎么回、多久放一次、放多久、放了之后倍率/范围/目标数变成什么**。

## 1. 技力（SP）回复方式
| 类型 | 规则 | 特点 |
|---|---|---|
| 自动回复 | 默认约 1 点/秒（受技力回复速度影响） | 最稳定，适合长线 |
| 攻击回复 | 每次普攻 +1 | 攻速越快回得越快，怕不能攻击 |
| 受击回复 | 每次受击 +1 | 高压反而回得快，怕没敌人打 |
| 其他 | 技能/天赋直接给技力、击杀回技力、初始技力 | 决定开局能不能立刻开技能 |

- 技能面板三要素：**初始技力 / 消耗技力 / 持续时间**。
- 撤退/再部署会清空技力（部分干员有“魔力”机制例外：整场继承）。
- 阻回（技能期间停止自然回技力）、静默（不能开技能）是常见针对手段。

## 2. 技能类型
- **手动触发**：看轴，上限高，适合高难。
- **自动触发**：挂机友好，但可能空放。
- **持续型**：一段时间内持续生效（多数输出/奶）。
- **瞬发型**：一次性爆发（如爆发法术/位移）。
- **弹药型**：有弹药数，打完结束；可被“补弹”。
- **切换型**：开/关两种状态。
- **蓄力**：技力可存到 2 倍上限，开技能触发额外效果。
- **过载**：技能进行到一半触发强化（后半段更强）。
- **维持技能状态**：开启后不普攻，持续执行技能效果（如星熊三技能、伊芙利特三技能）。

## 3. 专精到底提升什么
专精（M1→M3）通常提升以下一项或多项：
1. **倍率**（攻击力倍率/治疗倍率/伤害倍率）
2. **持续时间**
3. **消耗技力 / 初始技力**（最关键，可能改变循环）
4. **范围 / 目标数 / 命中数**
5. **冷却 / 附加效果概率**

### 判断“值不值得专三”的三个问题
1. **有没有质变点？** 例如消耗技力从 30→28，配合天赋/队友能多放一次；持续时间从 20s→25s 刚好覆盖一波。
2. **这个技能是不是队伍的核心循环？** 核心输出/产费/群奶的技能值得；只在特定关用的对策技能，专一够用。
3. **专精后能不能过“阈值”？** 伤害刚好够秒精英、奶量刚好够扛住领袖一击——这种专精最值。

## 4. 优先级建议
| 优先级 | 技能 |
|---|---|
| 最高 | 产费先锋的回费技能（桃金娘类）、主力输出核心技能、群奶技能 |
| 高 | 关键控制/减速/削防技能、快速复活的核心技能 |
| 中 | 对策技能（只在高难关用） |
| 低 | 纯数值小幅提升、自动触发且容易空放的技能 |

## 5. 专精成本与节奏
- 消耗：**技巧概要·卷1/2/3**（CA-5 产出）+ 对应材料 + 龙门币；专三还要紫/金材料。
- 在训练室进行，可派干员进驻缩短时间；训练位干员期间不能出战。
- 一个干员通常只专 **1 个技能**；专精错技能 = 浪费一周材料。
- 顺序：精二 → 开关键模组 → 专三核心技能 → 再考虑第二技能。

## 6. 常见误区
- 只看“专三倍率更高”就专，忽略了 SP/持续时间的质变。
- 给“挂机自动技能”专三，但实战中根本不开手动。
- 把材料摊给 5 个干员的 M1，不如集中 1 个 M3。
- 忘了模组也吃材料——先确认模组和专精哪个收益大。
