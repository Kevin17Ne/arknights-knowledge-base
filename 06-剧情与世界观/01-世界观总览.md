# 泰拉世界观总览（剧情入门）

> 来源：PRTS「泰拉年表」（22 万字符，按年份编排）、章节标题、活动页
> 用途：看懂活动剧情/干员档案的背景；细节以游戏内剧情为准。

## 1. 基础概念
- **泰拉（Terra）**：游戏所在大陆，国家以“移动城市”为主要形态。
- **源石**：万能源泉，也是灾祸根源；能引发**源石技艺**（法术）。
- **矿石病**：源石感染导致的绝症，感染者体表结晶、被社会歧视；死后可能成为新的感染源。
- **天灾**：源石引发的自然灾害，移动城市就是为了躲避天灾。
- **感染者**：矿石病患者，社会地位低下，是多数冲突的根源。
- **种族**：泰拉有大量亚人种族（菲林、鲁珀、萨科塔、萨卡兹、阿戈尔、瓦伊凡等），种族矛盾（尤其对萨卡兹）是核心政治议题。

## 2. 主要势力（政治实体）
| 势力 | 特征 |
|---|---|
| **乌萨斯** | 军事帝国，皇帝与贵族，感染者政策严酷；整合运动发源地之一 |
| **维多利亚** | 老牌帝国，王位空缺，公爵割据；伦蒂尼姆是主线后期舞台 |
| **哥伦比亚** | 科技与资本强国，莱茵生命、黑钢国际等企业活跃 |
| **莱塔尼亚** | 法术之国，选帝侯与术师传统 |
| **叙拉古** | 家族（黑手党）政治，法治薄弱 |
| **卡西米尔** | 骑士竞技与商业化的国度，骑士阶层没落 |
| **谢拉格** | 雪山小国，宗教（耶拉冈德）与封闭传统 |
| **炎 / 龙门** | 东方风格大国，龙门是独立城邦（近卫局） |
| **拉特兰** | 萨科塔的宗教国家，律法与“共感” |
| **萨尔贡** | 沙漠与王酋，雇佣兵与古文明遗迹 |
| **伊比利亚** | 曾称霸海洋，因“大静谧”衰败，审判庭掌权 |
| **阿戈尔** | 海底文明，与海嗣战争数百年 |
| **玻利瓦尔 / 米诺斯 / 萨米 / 卡兹戴尔** | 战乱/小国/萨卡兹故土等 |

## 3. 关键组织
- **罗德岛**：制药公司+武装组织，研究矿石病，本作主角方。
- **整合运动**：感染者武装，切尔诺伯格事变的主谋（主线 0~8 章对手）。
- **巴别塔**：罗德岛前身/旧组织，与特蕾西娅、特雷西斯、凯尔希的过去相关。
- **深池**：维多利亚的感染者/民族主义组织。
- **维多利亚军事委员会**：特雷西斯一派，伦蒂尼姆的实际控制者。
- **深海猎人**：阿戈尔对海嗣的精英部队（斯卡蒂、歌蕾蒂娅、幽灵鲨、乌尔比安）。
- **审判庭**：伊比利亚的宗教裁判机构。
- **莱茵生命**：哥伦比亚科研巨头（“孤星”事件核心）。
- **黑钢国际 / 企鹅物流 / 鲤氏侦探事务所**：佣兵/物流/侦探等民间组织。
- **岁**：炎国的“岁相”与十二碎片（年、夕、令、重岳、黍等）。

## 4. 主线时间线（按章节）
> 依据年表中各章引用推断，剧情内时间跨度约 **1096~1099 年**；活动剧情最远到 **1103 年**。
| 年份 | 章节 |
|---|---|
| 1096 | 序章~第 4 章（切尔诺伯格事变、整合运动） |
| 1097 | 第 5~8 章（龙门、霜星、爱国者、怒号光明） |
| 1097~1098 | 第 9~14 章（维多利亚：风暴瞭望、破碎日冕、淬火尘霾、惊霆无声、恶兆湍流、慈悲灯塔） |
| 1098~1102 | 第 15~17 章（离解复合、反常光谱、相变临界） |

## 5. 标志性历史事件（年表可查）
- **切尔诺伯格事变（1096）**：整合运动袭击切城，博士苏醒的起点。
- **罗德岛营救博士（1096 末）**：主线开局。
- **深海猎人讨伐“初生”（1096）**：官方宣布全员阵亡，实际数人存活。
- **伦蒂尼姆事件（1098 前后）**：维多利亚王位、萨卡兹、特雷西斯的核心冲突。
- **孤星事件（1097）**：莱茵生命与哥伦比亚的太空/静滞所线。

## 6. 剧情阅读建议
1. 先打主线 0~8 章（理解罗德岛 vs 整合运动）。
2. 再看「生于黑夜」「沃伦姆德的薄暮」等插曲补维多利亚/萨卡兹背景。
3. 活动剧情按实装顺序看；复刻活动可走「记录修复」补限定奖励。
4. 干员档案（精英化/信赖解锁）是角色塑造的主要来源，别跳过。
5. 想深挖时间线，直接查 PRTS「泰拉年表」按年份检索。

## 7. 与玩法的关系
- 活动机制常与剧情设定绑定（如深海=海嗣/神经损伤、莱茵=科技装置、岁=火锅/年兽机制）。
- 了解势力设定有助于预判活动主题与敌人类型。
