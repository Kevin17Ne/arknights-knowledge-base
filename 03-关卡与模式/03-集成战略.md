# 集成战略（Roguelike / IS）总览与当前主题

> 来源：PRTS「集成战略」「沉沦者的黑流树海」
> 当前主题：**沉沦者的黑流树海**（2026-07-17 ~ 2027-03-10），解锁条件通关主题曲 3-8

## 1. 通用规则
- **不消耗理智**，不计模组任务；用「招募券 + 希望」组队，节点随机，收藏品强化。
- 招募/进阶消耗希望：
  | 稀有度 | 招募 | 进阶(精二) |
  |---|---|---|
  | 6★ | 6 | 3 |
  | 5★ | 3 | 2 |
  | 4★ | 2 | 1 |
  | 3★ 及以下 | 0 | — |
- 其他资源：**源石锭**（货币，买收藏品/选行动）、可携带干员数、可同时部署人数。
- **完美作战**：不掉目标生命即算，连续完美会累计“完美的战术”计数（用于部分收藏品/结算）。
- 难度：普通 → 1~15 级（每级叠加负面、提高积分倍率）；自「萨卡兹的无终奇语」起有 **16~18 级**；最高难度之后积分不再提升。简单难度已取消。
- **战术分队**：历史上共 41 种（指挥/集群/后勤/矛头/突击/堡垒/远程/破坏/研究/高规格/心胜于物/物尽其用/以人为本/永恒狩猎/生活至上/科学主义/特训/因地制宜/魂灵护送/博闻广记/蓝图测绘/点刺成锭/拟态学者/异想天开/专业人士/高台突破/地面突破/游客/司岁台/天师府/花团锦簇/棋行险着/岁影回音/代理人/知学/商贾/本源研修/文明开化/开拓者/多边贸易/地质调查），不同主题可用集合不同。
- **初始招募组合**（6 选 1）：先手必胜（先锋/狙击/特种）、稳扎稳打（重装/狙击/术师）、取长补短（近卫/医疗/辅助）、灵活部署（先锋/辅助/特种，岁的界园志异新增）、坚不可摧（重装/术师/医疗，新增）、随心所欲（随机三张，必含 4★ 临时招募）。
- 其他模式：**月度小队**（固定干员+收藏品，完成委托即结算）、**特勤培训**（培养主题专属干员）。

## 2. 当前主题「沉沦者的黑流树海」的独特机制
### 地图与行动力
- **平面图式地图**（非线形），所有节点初始未知；能观测到的只有与当前位置连通、且中间无未完成节点的格子。
- **行动力**：每层初始若干，徒步每经过 1 格消耗 1 点；不能越过未完成节点。
- **加工品**（零件的一类）：装载后可无视距离/越过未完成节点，只花 1 点甚至 0 点行动力，但有使用次数，耗尽损毁。
- 行动力耗尽仍未离开本层 → **追猎战**（猎犬）；存活可继续，但通常追猎只掉 1 张招募券；「险路恶敌」层的追猎正常掉落。追猎后获得“探测先锋”奖章：下层初始行动力 −1、记录追猎次数、猎犬 proto 变强。

### 出口（三种）
| 出口 | 效果 |
|---|---|
| 险路尽头 | 取出留存招募券、得 1 个加工品、剩余行动力转希望 |
| 险路小径 | 得较稀有加工品、携带剩余行动力到下一层 |
| 险路恶敌 | 领袖战，胜利后剩余行动力转希望 |

### 招募券留存
- 可“留存招募券”稍后再用，上限 **3 张**；只能在「险路尽头」或点亮生命游戏“血管”的「安全的角落」取出。
- 取出时随机效果（直升/随机干员/临时招募）**重新判定**。

### 零件（三类）
- **加工品**：装载后提供移动能力，有次数。
- **自然物**：不能使用，估价高，可卖给行商换源石锭；部分有被动效果。
- **概念体**：携带后被动激活，提供一次性增益/资源，也有无限次的。
- 获取：战斗掉落、花 50 费开启「丰饶树冢」、过层奖励、行商购买。零件箱有容量，**超载无法行动**，需要丢弃。

### 种子与园圃
- 种子是特殊自然物，可在「秘境行商」的机械师园圃培育，产出随机零件或给下次探索助力的「襁褓生灵」。

### 理想域（2+ 难度）
- **实托邦**：进新层概率刷新，以“理想源”为中心覆盖一片区域，区域内节点带雾状特效；破坏理想源（必定是紧急作战）可消除。理念效果随难度加深，6+ 难度额外有“方针”。
- **乌托邦**：通过「误入奇境」进入黑潭时固定触发，覆盖全图。

### 宝箱/恶笼草（每个作战节点独立两次随机）
| 结果 | 单点概率 |
|---|---|
| 不出现 | 81.73% |
| 恶笼草（+2 源石锭） | 10.10% |
| 畸变恶笼草（反弹伤害，+5） | 3.37% |
| 丰饶树冢（50 费开，得 1 零件） | 3.37% |
| 箱型恶笼草（+10，但进目标点偷 10） | 1.44% |
- 每关：完全没有宝箱 66.8%，至少 1 个 33.2%。

### 其他
- **应急雇佣**：缺人时临时雇 1 名干员，只能打 1 场，不能转正、不能“先行一步”。
- **空值体**：伪装成见过的敌人并拥有其全部能力，受伤即现形——不受伤就一直是它伪装的样子。
- **源流堆栈**（通行证）：探索分数 = 层数分（0/40/80/150/270/400/550/650）+ 步数×1 + 普通战斗×10 + 招募×2 + 获得物品×5 + 领袖×30 + 精英×20，再乘难度倍率；分数 1:1 转源流样本（生命游戏可提升至 +10%~16%）。等级 1~50，主题完结后可用源石买级。
- **特勤培训**：源流堆栈 1 级获得干员「机械师」，做任务养成。

## 3. 打法框架
1. **开局定体系**：分队 + 招募组合决定这局玩什么（地面突破/高台突破/商贾/点刺成锭等），不要中途摇摆。
2. **希望是硬通货**：6★ 招 6 希望、进阶 3，前期宁可拿 4★ 过渡，把希望留给核心 6★ 的进阶。
3. **行动力=路线规划**：本主题先算“到出口要几步”，再用加工品抄近路；宁可少打一个普通节点，也别被迫追猎。
4. **收藏品优先“乘算型”**：攻击力% / 伤害% / 费用回复 / 部署位，比固定数值强。
5. **高难（12+）**：实托邦理念会叠负面，优先清理想源；16+ 难度下险路尽头不给加工品，路线更紧。
6. **分奴 vs 高难**：分奴追求“稳定通关+高通过层数”，高难追求“极限构筑”，两者收藏品取舍完全不同。
