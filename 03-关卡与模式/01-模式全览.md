# 明日方舟 · 游戏模式全览（2026-10 版）

> 来源：PRTS「关卡一览」「活动一览」「危机合约」「生息演算」「保全派驻」「卫戍协议」「争锋频道」「矢量突破」「全息作战矩阵」

## 一、入口分类（终端 → 作战）

| 大类 | 内容 | 消耗理智 | 说明 |
|---|---|---|---|
| 主题曲 | 主线 0~15 章 + 磨难/剧情模式 | 是 | 首通源石、素材、干员信赖 |
| 插曲 | 已复刻的大型活动（可常驻打） | 是 | 打素材/补剧情 |
| 别传 | 小型活动复刻 | 是 | 同上 |
| 资源收集 | 物资筹备（LS/CE/AP/SK/CA）+ 芯片搜索（PR-A~D） | 是 | 日常养成核心 |
| 常态事务 | 剿灭作战、保全派驻 | 是（剿灭有每周上限） | 每周合成玉来源 |
| 长期探索 | 集成战略（肉鸽）、生息演算（经营） | **否** | 不耗理智，独立奖励线 |
| 周期挑战 | 全息作战矩阵、危机合约、矢量突破 | **否** | 高难/评分/蚀刻章 |
| 悖论模拟 | 干员专属教学关 | 否 | 给合成玉/素材 |
| 训练场 | 试玩关卡 | 否 | 练手 |

## 三、剿灭作战（每周合成玉）
- 长线刷怪图，单局人数/击杀极多，费用上限 999；每周有击杀数奖励上限（合成玉）。
- 目前新增「米诺斯 灰石剧场」（2026-10 新增）。
- 打法：堵门/挂机阵容，追求稳定代理；周常必打满。

## 四、保全派驻（Stationary Security Service）
- 干员可**接力替换**（同位置换人）、有定向导能元件（装备）。
- 分层推进，强调“轮换+装备构筑”，不吃理智。
- 详见 `99-原始资料/保全派驻.wiki`（后续精读）。

## 五、集成战略（Roguelike，简称 IS）
- 不耗理智、不计模组任务；用「招募券+希望」组队，节点随机，收藏品增强。
- 主题演进：刻俄柏的灰蕈迷境(IS1) → 傀影与猩红孤钻(IS2) → 水月与深蓝之树(IS3) → 探索者的银凇止境(IS4) → 萨卡兹的无终奇语(IS5) → 岁的界园志异 → **沉沦者的黑流树海（当前主题，2026-11 有月度更新）**
- 每月更新内容/月度任务；难度分级（含“深入调查”式高难）。
- 核心能力：分奴（稳定通关）vs 高难（N15/深入调查）；需要熟悉收藏品与事件池。

## 六、生息演算（Reclamation Algorithm，经营+塔防）
- 基地建设、外出采集、敌袭防守，回合制推进；不耗理智。
- 当前主题：**重启锚点**（2026-05-15 ~ 2027-05-15）。
- 核心：资源循环（水/食物/建材）、探索队配置、基地防线布置、事件抉择。

## 七、危机合约（Contingency Contract，CC）
- 自选「指标/合约」叠加难度，冲高分；有赛季轮换。
- 当前：新#5 赛季「涤墨作战」（2026-06-26~07-10，已结束），前回「弧光作战」。
- 经典赛季已归档；新赛季为“新#N”编号。
- 技巧：先规划“必须处理的机制”（免疫/费用/禁疗等），再选合约；顶层靠干员池深度与轴。

## 八、全息作战矩阵（Holographic Combat Matrix，常驻）
- 以危机合约为蓝本的重构关卡，**常驻、不定期加批次**，不耗理智。
- 解锁：通关 H5-1 / H9-1 / H15-1 之一。
- 指标分两类：
  - **基础指标**：每个分组必选 1 个，不计分；带 📌FXD 的“唯一锁定指标”会剧变关卡。
  - **附加指标**：自由选择、互相可能冲突，**只有附加指标计分**。
- 评分 8 分得蚀刻章，15 分镀层。

## 九、矢量突破（Vector Breakthrough）
- 周期挑战，按“批次”出题：#0、#1 无机物、#2 巫术之夜、#3 拟生态（当前）。
- 用“考核程序”构拟的极限关卡，考验干员池与轴。

## 十、卫戍协议（自走棋+塔防）
- 全自动塔防 + 自走棋：调配资金与干员，构筑阵线防守。
- 干员按「综合行动效率评价体系」分**等阶**，以固定养成状态出战（初始/精锐），只能改技能与模组；缺干员用“原型干员”填补。
- 每波只出现一类敌人（悬赏/策略除外）。
- 当前：2026-11-08 开启「卫戍协议·规程」。

## 十一、争锋频道（愚人节玩法）
- 观赛竞猜：选队伍、看自动战斗，场地攻击力 150%、最大生命减半；1 分钟后源石兴奋圈收缩，圈外攻击翻倍但持续掉真实伤害。
- 短期限时，纯娱乐+奖励。
