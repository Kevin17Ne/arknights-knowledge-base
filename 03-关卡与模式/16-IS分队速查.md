# 集成战略「沉沦者的黑流树海」分队速查

> 来源：PRTS 主题页「选择分队」｜当前主题新增/调整了分队，部分需在【生命游戏】点节点解锁或升级。
> 标注：`<X+>` 表示难度 ≥X 才生效；① ② 表示叠加升级。

## 1. 本主题新分队（优先了解）
| 分队 | 效果 |
|---|---|
| **本源研修** | 招募/进阶 4 星以上【本源术师/本源铁卫/本源近卫/巫役】希望 −2；初始携带【河谷祭祈】 |
| **文明开化** | 消除实托邦理想源 → +2 行动力 + 随机收藏品；① 不受实托邦·方针影响；通过追猎进入下一区域时实托邦概率提升（1 层 10%、2 层约 75%、3~6 层约 99%） |
| **开拓者** | ① 初始携带 1 个 ②（稀有的）加工品；进入新区域获得 1 个随机加工品或概念体；初始携带<旅行绒> |
| **多边贸易** | 零件箱容量 +2 ① +4；同一行商节点卖出 3 个零件 → 8 源石锭；① 每次进行商节点获得<枯苔藓球>；② 初始携带 3 个 |
| **地质调查** | 初始携带【黑流树海笔记】；通过探访不同类型节点，提升战斗后获得收藏品的概率 |

## 2. 通用核心分队
| 分队 | 效果 |
|---|---|
| 指挥 | 目标生命上限 +2；每战额外回复 1 目标生命；`<3+>` 战后护盾<5 时 +1 护盾 |
| 特勤 | 可携带干员 +2、可同时部署 +2；初始 5 名罗德岛预备干员 + 临时招募机械师（精 2 机械师解锁） |
| 后勤 | 初始源石锭 +20、初始希望 +2；`<6+>` 初始携带<多生苔藓> |
| 地面突破 | 招募 4 星以上【先锋/近卫/重装/特种】希望 −2 |
| 团结阵线（拓展Ⅰ） | 应急助力不再消耗源石锭；初始携带【似曾相识棋盒】；部署 +1；进入下一区域获得应急干员 |
| 踏足遍历（拓展Ⅰ） | 使用加工品移动后随机揭露 3 处节点视野；初始携带《去踏足》；全图视野揭露时获得源石锭 |

## 3. 选分队思路
- **走元素体系** → 本源研修（希望 −2 直接滚雪球）
- **走行动力/路线运营** → 开拓者（加工品多）、踏足遍历（视野）
- **稳健分奴** → 指挥（生命+护盾）、特勤（人多）
- **经济流** → 后勤（源石锭+希望）、多边贸易（卖零件换钱）
- **想刷实托邦/高难** → 文明开化（实托邦概率与理想源收益）
- 分队解锁条件多为“用某分队通关一次”或“生命游戏点节点”，先解锁再谈强度。

## 4. 与收藏品/事件的联动
- 分队决定“希望/源石锭/行动力/零件”四条资源的偏向，收藏品与事件应按这个偏向取舍（见 `10-IS收藏品与事件策略.md`）。
- 例如走本源研修，就优先抓元素类收藏品与巫役/本源干员；走多边贸易，就多进行商卖零件。
