# 活动结构与复刻规则

> 以 2026-10「昨日海」（YW 系列）为样本，说明 SideStory 的标准结构与资源规划。

## 1. 活动类型
| 类型 | 特征 | 例 |
|---|---|---|
| **支线故事 SideStory** | 有完整关卡组 + 商店 + 蚀刻章，一年左右复刻 | 昨日海（YW）、时间啊，向前！（11-01） |
| 故事集 | 以剧情为主，关卡少 | — |
| 联动活动 | 独立规则，限定池可能有 120 抽硬保底 | 恒远津梁（×国家图书馆）、Persona3 |
| 签到/登录 | 纯福利 | 感谢庆典签到 |
| 新玩法 | 独立规则的模式型活动 | 视相博物馆（街机）、卫戍协议、矢量突破 |
| 网页活动 | 游戏外，领蚊子腿 | 冻土与火种 |

## 2. SideStory 的标准关卡结构（昨日海为例）
| 关卡 | 作用 | 消耗 |
|---|---|---|
| YW-ST-1 | 纯剧情，无战斗 | 0 |
| YW-1 ~ YW-N | 主线关卡，首通给源石 + 代币 | 9~21 理智 |
| YW-TR-1 | 教学关（教机制） | 0 |
| YW-EX-1 ~ EX-N | 高难关，首通源石 | 更多理智 |
| 突袭 | EX 关的高难版，首通源石 + 蚀刻章 | 演习券/理智 |
- **每关三星首通 = 1 至纯源石**，是活动最重要的固定收益。
- 代币（昨日海是「未来瞻望镜」）来自关卡掉落与任务，用于商店兑换。

## 3. 商店兑换优先级
1. **龙门币 / 作战记录**（永远缺）
2. **芯片 / 双芯片**（精英化卡点）
3. **T4 紫材料 / T5 金材料**（专精卡点）
4. **寻访凭证 / 招聘许可**
5. 干员信物 / 时装 / 家具（收藏向，最后）
- 活动关的材料掉率通常**高于主线**，所以活动期间理智优先刷活动关。

## 4. 复刻与记录修复
- 活动一般在一年左右**复刻**；复刻期间商店与关卡重开。
- **记录修复**：可领取当年错过的限定奖励（干员/时装/家具）。
- 复刻结束后，部分奖励会**上架黄票/蓝票商店**，不再复刻——所以首次活动尽量拿。
- 复刻活动的代币规则可能与首开不同，注意公告。

## 5. 资源规划（活动期 vs 长草期）
| 时期 | 理智去向 |
|---|---|
| 活动期 | 首通拿源石 → 刷活动材料/代币 → 搬空商店高价值项 |
| 长草期 | 补主线材料、CE-6/LS-6、专精材料 |
| 活动最后 2 天 | 清代币（会过期）、补没打的 EX |

## 6. 联动活动注意
- 联动池限定干员**不进标准池**，池子规则特殊（可能有硬保底）。
- 联动时装/家具通常绝版，看需求。
- 联动关卡机制常绑定 IP 设定（如国家图书馆 = 典籍/书页机制）。
