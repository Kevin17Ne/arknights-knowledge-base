## 第 3 步：难点
1. **初始 0 费**：不能开局下重装，必须先用低费先锋/召唤撑过前 10~20 秒。
2. **双领袖**：
   - 梅菲斯特是**治疗型**，不先处理他会一直奶，战线被拖住 → **优先斩首**（真伤/爆发/快速复活切后排）。
   - 浮士德**超远射程**，等价于“专打你最后部署的人” → 部署顺序要设计，或高台诱饵。
3. **粉碎攻坚手（防 A / 抗 E）**：物理几乎打不动，但法抗极低 → **法术输出**是答案。
4. **特战术师（抗 A）**：法抗高 → 用物理打。
5. **弩炮台**：持续物理伤害，高台/后排需要奶或屏障。

## 第 4 步：阵容骨架
- 产费 2：低费先锋优先（初始 0 费，越快越好）
- 地面 2~3：能扛拾荒者的盾 + 群攻近卫
- 高台 2：**法术输出**（打攻坚手）+ 物理狙（打特战术师/浮士德）
- 治疗 1~2：群奶应对弩炮台与拾荒者
- 快活/真伤 1：切梅菲斯特

## 第 5 步：轴
1. **0 费开局**：先下低费先锋（或召唤物），费用回起来再下主盾。
2. **前期**：宿主群靠群攻+阻挡；弩炮台位置不要站脆皮。
3. **中期**：粉碎攻坚手出现 → 法伤集火；特战术师 → 物理点掉。
4. **领袖**：优先切梅菲斯特（禁疗/沉默更好），再处理浮士德；浮士德阶段注意最后部署位。
5. **收尾**：守住 3 点耐久，别让拾荒者漏过去。

## 第 6 步：结论
5-10 是“**开局经济 + 双领袖优先级 + 物法分工**”的综合考试：
- 0 费开局 → 低费先锋/召唤
- 梅菲斯特 → 先杀（治疗型）
- 粉碎攻坚手 → 法伤
- 特战术师 → 物理
- 浮士德 → 控部署顺序
