# 危机合约（新赛季）与全息作战矩阵：冲分机制

> 来源：PRTS「危机合约」「全息作战矩阵」
> 当前：危机合约新 #5 赛季「涤墨作战」（2026-06-26~07-10，已结束），前回「弧光作战」

## 1. 新赛季危机合约：从“选合约”变成“连通路”
- 原型来自「尖灭测试作战」。玩家从路径图上一个**可用起点（圆圈）**开始，把指标连成一条**通路**，只有通路上的指标才生效。
- 一次作战可建多条通路以选更多指标；取消某指标时，若后续指标再也连不到任何起点，会被一起取消。
- 少数指标是 **OR 分组**（组内互斥），只能选一个。
- **指标评分**：参与作战的指标评分之和 = 本次总分，并细分为六个维度：
  | 维度 | 含义 | 典型效果 |
  |---|---|---|
  | 战略 | 更强的敌人 | 全体敌人属性提升 |
  | 技巧 | 精英敌人控制/强化 | 特定敌人出现、加能力 |
  | 调遣 | 限制干员与部署 | 职业/费用/编队/部署人数限制 |
  | 应变 | 我方被削弱 | 全体我方属性降低 |
  | 洞察 | 战场环境 | 地块封锁、额外小怪、最终防线 |
  | 筹划 | 需要针对性战术 | 地图机制变更 |
- **指标集**：强关联指标群；选满该集合内最高分指标才算“选择该指标集”，部分指标集提供额外分（只在选满时生效）。指标集与下属指标的维度可以不同（“混装”）。
- **特殊节点**：
  - **晶块陈列室**：一次行动同时完成相连的指标集 → 得“结晶瑰宝”（赛季后上常设兑换所）。
  - **阵眼任务**：按要求完成任务 → 领奖励，并把该节点变成新的**可用起点**（扩展通路的关键）。
- **圣所评喻**：系统按作战风格/编队给出评价，结算时显示；作战回顾可看历史最高总分、六维图、回顾焦点（#2 起）。
- 货币：**晶体合约赏金**（赛季货币，可跨赛季保留）。

## 2. 全息作战矩阵（常驻，以 CC 为蓝本）
- 解锁：通关 H5-1 / H9-1 / H15-1 之一；入口：终端 → 周期挑战；不耗理智。
- 指标两类：
  - **基础指标**：每个分组必选 1 个，**不计分**；带 📌FXD 的“唯一锁定指标”会剧变关卡，务必先看。
  - **附加指标**：自由选择（有冲突项），**只有附加指标计分**。
- 评分 8 分 = 蚀刻章；15 分 = 蚀刻章镀层。

## 3. 冲分思路（通用）
1. **先读锁定指标**：FXD/唯一锁定往往决定这关“还能不能打”，它决定阵容大方向（如禁高台、费用翻倍、敌人强化）。
2. **优先选“不改轴”的指标**：数值型（敌人攻防+、我方攻防−）通常比机制型（地块封锁、额外敌人、职业禁用）好处理；机制型留到最后补分。
3. **指标集凑满再补单点**：指标集额外分只在选满时给，散点凑分效率低。
4. **阵眼任务是“滚雪球”**：完成一个任务多一个起点，后续能连更多高分指标，优先做。
5. **六维均衡拿评喻**：圣所评喻看风格，想刷评价就别只堆一个维度。
6. **顶层靠干员池**：高难最终拼的是“有没有能单解机制的对策卡”（无视闪避、真伤、元素爆条、强控、费用回复）。

## 4. 高难关卡通用检查表
- 敌人：防御/法抗/重量/元素抗性/是否飞行/是否免疫控制
- 我方限制：费用回复、部署位、职业禁用、再部署
- 地图：地块封锁、最终防线、地形伤害、装置
- 胜利条件：漏怪数、时间限制、保护目标
- 对策：物理穿透（黑/远牙）、法术穿透、真实伤害、元素爆条、推拉位移、沉默/冻结/眩晕、费用爆发（桃金娘/伊内丝）
