## 1. 收藏品（拟造物质）
- 编号 No.001~232+，分六类：**多元奇物**(13)、生存助力(24)、斗争之物(105)、专业工具(46)、巧用收藏(38)、支援道具(6)。
- 稀有度 0/1/2 = **低/中/高**；在坎诺特商店售价分别 **8 / 12 / 16 源石锭**。
- 状态：**未解锁**（需在常规行动达成条件）→ **未拥有** → **已拥有**；已解锁≠能抽到，图鉴状态只影响“能否出现”。
- 特殊标记：
  - 计数（stack）：可叠层，条件触发累加
  - 一次性（one-off）：生效后标“已使用”
  - 不可交易：不能在「失与得」交换
  - 追猎相关：影响追猎战
- **难度强化机制**：难度 3~5 / 6~8 / 9+ 时，「多元奇物」类效果依次升级为 **半结构化 / 非结构化 / 混沌化**（数值变强）。

## 2. 收藏品取舍原则
1. **乘算型 > 固定值**：攻击力%、伤害%、攻速%、费用回复、部署位/携带位，越早拿越滚雪球。
2. **稀有度不等于强度**：高稀有度多为“机制型/双刃剑”，低稀有度常有稳定小增益。
3. **看体系**：抓了法术 C 就优先法伤/削抗/技力；走召唤就抓召唤物强化。
4. **生存类别全跳过**：目标生命、护盾、治疗加成在高层难度是容错。
5. **商店只买“成型件”**：源石锭要留给关键收藏品或加工品，不要见啥买啥。

## 3. 事件（不期而遇）
- 事件有楼层限制（I~VI），同一事件可能重复出现（有概率）。
- 选项通常四类：
  | 类型 | 例子 |
  |---|---|
  | 白给增益 | +希望、+源石锭、+目标生命上限、+护盾 |
  | 交易 | 花源石锭换收藏品/加工品/零件 |
  | 风险 | 扣生命/护盾换稀有收藏品，或战斗 |
  | 拒绝 | 直接离开（无收益无损失） |
- **价值排序（通用）**：希望 ≈ 招募券 > 高稀有收藏品 > 源石锭 > 目标生命上限/护盾 > 零件。
- 前两层优先拿“希望/招募券”，中期拿“体系收藏品”，后期缺容错再补生命/护盾。
- 事件里的“消耗一半源石锭/生命”这类，先看当前资源再选，别在关键节点前清空。

## 4. 与地图/行动力的配合
- 事件节点也是“消耗行动力”的节点；行动力紧张时，宁可跳过无收益事件直奔出口。
- 可重复节点（标 ⟳）可以反复进，但每次都要花行动力。
- 「秘境行商」「诡意行商」是买东西的节点，源石锭在此转化为战力。
- 追猎战不计节点效果，收藏品里“追猎相关”的才有用。
