## 3. 核心难点
1. **毒性雾霾**：全场持续掉血 → **奶量需求远高于普通图**，单奶不够，建议双奶/群奶。
2. **地形曲折 + 远程不利**：高台射界被切碎，远程输出效率下降 → 需要近战核心或能覆盖多路的高台位。
3. **粉碎攻坚组长（防 S / 抗 E）**：物理完全打不动，**法术输出**是唯一高效解。
4. **高能源石虫群**：自爆伤害会连累站位密集的单位，**别把干员挤在一起**。
5. **弑君者**：闪现难锁定 → 真伤/范围伤害/预判位置。

## 4. 阵容骨架
- 产费 2：低费优先（初始 5 费）
- 地面 3：高防盾（扛攻坚组长）+ 群攻近卫
- 高台 2：**法术输出**（打重甲）+ 一个能覆盖多路的远程
- 治疗 2：**群奶 + 单奶**（毒雾刚需）
- 自由位：快活/控制（处理弑君者）

## 5. 轴
1. 开局：5 费先下低费先锋，别急着下盾。
2. 前期：特战士兵海用群攻清；注意别让高能源石虫贴脸自爆。
3. 中期：粉碎攻坚组长/重装防御组长 → 法伤集火，物理队会卡死。
4. 弑君者：留爆发/控制，别用普攻追。
5. 收尾：毒雾持续掉血，奶量要留余量，别让干员在毒里慢慢死。

## 6. 结论
H5-3 是“**续航 + 法伤 + 站位**”的考试：
- 毒雾 → 双奶/群奶，奶量就是容错
- 重甲 → 法伤（防 S 的攻坚组长是硬门槛）
- 地形 → 别迷信高台，近战核心更稳
- 自爆虫 → 分散站位
