# 抽卡规则与资源规划（2026-10）

> 来源：PRTS「寻访规则」

## 1. 基础概率
| 稀有度 | 概率 |
|---|---|
| 6★ | 2% |
| 5★ | 8% |
| 4★ | 50% |
| 3★ | 40% |

## 2. 保底机制（通用）
- **软保底**：连续 50 抽没有 6★ 后，第 51 抽起每抽 6★ 概率 +2%（4%、6%、8%…直到 100%）。
- 抽到 6★ 后计数**重置为 2%**。
- **标准寻访之间计数继承**；**限定寻访之间不继承**（每期限定结束清零）。
- **新池前 10 抽必出 5★ 或以上**（每池一次）。

## 3. 各类池子的“选调/定向”机制
| 池型 | 机制 |
|---|---|
| 常驻标准寻访（双 UP 六星） | 累计 150 抽 → 下一个 6★ 必为 UP 之一；累计 300 抽 → 下一个 6★ 必为**另一名** UP。各生效一次 |
| 限时标准寻访（新干员单 UP） | 连续 150 抽没出 UP 6★ → 下一个 6★ 必为 UP（一次） |
| 常驻中坚寻访 | 同标准：150/300 选调；独立计数 |
| 限定寻访 | **300 抽额外赠送当期限定**（一次，需手动领，邮件可补 90 天）；**数据契约**每抽 1 张，交换所兑换指定干员 |
| 联合行动 | 6★ 只有 4 名特选，5★ 只有 6 名 |
| 前路回响 | 只含上三个主题曲的 6★ |
| 定向甄选 | 自选 3 名 6★ + 3 名 5★ 锁定 UP，6★ 只出这 3 名 |

## 4. 限定寻访（最重要的规划对象）
- 三个系列：**春节**（春节档，14 天）、**庆典**（5/1 与 11/1 起，各 14 天）、**夏季**（8 月，14 天）。
- 同类限定复刻：限定干员只会在**同类**限定池再次登场；当期“最新 3 名同类限定”享有 **5 倍权重**（歪的时候更容易歪到近期限定）。
- **限定不进入标准寻访**；每期限定结束后有最多 11 个月“解限期”，期间不会进任何限定池；**限定池不进行复刻**（历史上只有地生五金例外）。
- 数据契约：当期交换所可换当期/往期限定；2024-05-01 起，解限满 3 年（春节 4 年）的 6★ 限定兑换需求**永久降至 200**。
- 300 抽赠送的简历**不消耗概率、不产契约**。

## 5. 特殊池
| 池 | 规则 |
|---|---|
| 新人特惠寻访 | 单抽 380 玉，共 21 次（含教程 1 次），固定 6★ 池：银灰/能天使/山/棘刺/塞雷娅/煌（2024-08 起） |
| 跨年欢庆寻访 | 每年 1/1，首个 6★ 必为**未拥有**的干员（有分支：标准/中坚） |
| 新年特别十连 | 1/1 贩售，十连必得定制 3 名 6★ 之一 |
| 联动寻访 | 规则特殊，可能有 **120 抽硬保底**（如部分联动） |
| 归航寻访 | 离线 ≥180 天回归专用，6 名指定 6★ |
| 中坚甄选 | 自选 2 名 6★ + 3 名 5★，一号槽可兑换 |

## 6. 抽卡策略（结论）
1. **只抽限定/强力单 UP**：常驻池的 150/300 选调对无氪不现实，除非池子里有两个你都要的核心。
2. **攒井**：限定池按 300 抽规划（约 18 万合成玉）；不够 300 就按“捞到即停”而非“垫到保底”。
3. **优先级**：限定 > 改变环境的泛用核心 > 对策卡 > 厨力。联动池有硬保底时可考虑。
4. **不要为了 4★/5★ 抽**：5★ 会随着抽卡自然溢出，黄票才是真正货币。
5. 新池前 10 抽有 5★ 保底，想低成本试水可以只抽 10 连。

## 7. 凭证体系
| 凭证 | 来源 | 用途 |
|---|---|---|
| 资质凭证（绿票） | 公招、抽卡 3/4★、重复信物 | 采购中心换材料、招聘许可 |
| 高级凭证（黄票） | 抽到 4★ 以上（含重复） | 换六星干员、寻访凭证、材料 |
| 通用凭证 | 中坚规则下的获取 | 通用凭证区（中坚干员/材料） |
| 寻访数据契约 | 限定池每抽 1 张 | 当期限定交换所；过期 1:6 转寻访参数模型 |
| 寻访参数模型 | 契约过期转换 | 参数模型交换所换材料 |

> 经验：黄票 180 张可换一个六星（常规），所以“抽到重复 4★”也是资产；公招是零氪黄票的主要来源之一。
