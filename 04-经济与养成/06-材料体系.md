## 2. 加工站：合成与转换
- 基础规则：**3 个低档 → 1 个高档**（例：碳×3 → 碳素×1；碳素×3 → 碳素组×1）。
- 建材：碳×2 → 基础加固建材；碳素×2 → 进阶；碳素组×2 → 高级。
- 家具零件：碳×1 → 4 零件（碳素 8、碳素组 12）。
- **高阶材料可 1:1 或 2:1 转换**（例：RMA70-24 → D32钢 1:1；白马醇×2 → 双极纳米片；精炼溶剂×2 → 烧结核凝晶；酮阵列 → 聚合剂；糖组 → 手性屈光体；转质盐组 → 环烃预制体）。这就是“缺什么转什么”的底气。
- 副产物：基础概率由配方决定（多为 **10%**），进驻加工站干员可提升；不进驻则副产物概率锁 0%。
- 加工瞬时消耗心情，**不吃控制中枢的心情减免**。

## 4. 消耗结构
- **精英化**：芯片（职业芯片组 → 双芯片，制造站 1 秒合成）+ 蓝/紫材料 + 龙门币。
- **专精**：技巧概要（卷 1/2/3）+ 紫/金材料 + 龙门币。
- **模组**：模组数据块（解锁）+ 数据增补条（2 级）+ 数据增补仪（3 级）+ 材料 + 龙门币。
- 结论：**蓝材料是日常消耗主力，紫/金是卡点**；活动商店优先换紫/金与芯片。

## 5. 刷材料纪律
1. 先算“还缺多少”，别囤到溢出。
2. 活动期间集中刷活动关，长草期补主线缺口。
3. 加工站转换只用于“差一两个”的卡点，别把稀缺紫材料换光。
4. 刷图队里塞未满信赖干员。
5. 剿灭/资源关的理智别和活动抢——活动限时，资源关常驻。
