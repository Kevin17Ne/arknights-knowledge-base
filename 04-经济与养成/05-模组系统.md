# 模组系统（Module）

> 来源：PRTS「干员模组一览」「模组数据块」「数据增补条」「数据增补仪」+ 干员页模组数据

## 1. 基础规则
- 解锁条件：干员 **精英二 1 级**；仅 **4★ 及以上**有模组系统。
- 两类模组：
  - **基础模组**：无特殊效果（纯占位/属性）。
  - **专属模组**：有特殊效果，通常分 X/Y（部分干员有第三套），效果方向不同（输出/功能/生存）。
- 模组 **1~3 级**：
  - 1 级：解锁模组 + 基础属性/特性强化
  - 2 级、3 级：**常常直接强化天赋**（例：银灰 X 模组 2 级/3 级把“领袖”从 +10% 攻击提升到 +20%/+25%，并追加对精英/领袖的增伤与再部署光环）
- 模组任务：每套专属模组有对应任务（通关指定关卡/达成条件），完成后才能解锁。

## 2. 材料与来源
| 材料 | 用途 | 获取 |
|---|---|---|
| 模组数据块 | **解锁模组** | 教学送 4+4+4；采购凭证 120/个；高级凭证 20/个；任务/活动 |
| 数据增补条 | 升 **2 级** | 教学送 60；保全派驻；活动 |
| 数据增补仪 | 升 **3 级** | 保全演练全通送 20；保全派驻；活动 |

> 结论：模组材料是**长线稀缺资源**，主要靠保全派驻与活动，别指望采购中心大量买。

## 3. 开模组的判断标准
1. **改机制/改天赋的优先**：3 级天赋质变 > 纯数值。
2. **补短板的优先**：让上不了场的核心干员重新可用（如增加阻挡、范围、回费、生存）。
3. **主 C 的模组最后开**：主 C 本身已经能打，模组收益是锦上添花。
4. **不要平均主义**：一个 3 级模组的成本 ≈ 数个 1 级模组，集中给 2~3 个核心。
5. **看模组任务难度**：任务卡关就先放着，别为开模组硬打高难。

## 4. 模组与“强度”的关系
- 现在版本干员强度不只由精二决定，**模组能显著改变定位**（例：某些干员开模组后从“对策”变“泛用”）。
- 但模组不改变干员的基础职能：不会让一个纯输出变成奶。
- 社区讨论“X 模组/Y 模组哪个好”时，本质是在选“输出向 vs 功能向”，按你的队伍缺什么选。

## 7. 精确成本（实查干员页，结构统一）
| 阶段 | 材料 | 龙门币 |
|---|---|---|
| 解锁/1 级 | 模组数据块 ×4 + T5 材料 ×2 | 8 万 |
| 2 级 | 模组数据块 ×4 + 数据增补条 ×60 + T5 材料 ×3 | 10 万 |
| 3 级 | 模组数据块 ×4 + 数据增补仪 ×20 + T5 材料 ×4 | 12 万 |
| **一个模组开满** | **数据块 ×12 + 增补条 ×60 + 增补仪 ×20 + T5 ×9** | **30 万** |

- 前置：干员精英二、页面「解锁等级 60」、模组任务（部分干员还需信赖 100）。
- 例（银灰）：L1 聚合剂×2；L2 晶体电子单元×3；L3 烧结核凝晶×4。材料类型因干员而异，数量固定。
- 折算：一个 3 级模组 ≈ 60 条（保全派驻多周期）+ 20 仪（保全演练全通送 20）+ 9 个 T5（约 9×400 理智）。
